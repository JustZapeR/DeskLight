# Задачі DeskLight ЛР3

**Кандидат 29.10:** збірка `c26a59c` використовує SysTick із кроком 1 мс. Згадки TIM3 нижче описують попередні експерименти, а не поточну реалізацію. Короткий Wokwi pilot з UART/VCD виконано; незалежний аналіз 952 інтервалів ADC дав середній період 100012,632 мкс. Це не перевірка годинних сценаріїв або енергонезалежності. Дані: `docs/metrics/lab3/systick-pilot-20261029/` і `docs/captures/lab3/systick-pilot-20261029.vcd`.

Повторний pilot `8976c45` показав приблизно 128,85 с TIM3 при 35,86 с SysTick, а незалежний VCD дав середній період ADC 27,819 мс замість 100 мс. Збережено `docs/metrics/lab3/regression-20261029/uart.raw` та `docs/captures/lab3/regression-20261029.vcd`. Для нового кандидата короткі інтервали квантуються до 1 мс; нульова тривалість не означає нульового часу. `task_permille=unavailable`: такі відліки не дають надійної оцінки CPU. Для коротких інтервалів потрібні власні GPIO/VCD. Час у мікросекундах переповнюється через 4294,967296 с; unsigned різниці коректні для коротких проміжків.

Flash regression: `ERASE page=14 result=ERROR ff_bytes=0 sr=00000000`, `SAVE result=ERROR seq=0`. Перевірку всієї сторінки збережено. Результат стосується моделі, а не доводить несправність фізичного C031. Стирання, CRC/reset і обрив живлення потребують реального підтвердження.

Єдиний super loop, без RTOS, MCU STM32C031C6, 48 МГц. Стартовий main і HAL ЛР2 збережено. Board виконує до 32 RX-байтів і не більше однієї команди за прохід, PIR, ADC, IMU, control/LED/status, секундний зріз, контрольну точку. Перед кожною періодичною задачею читається актуальний таймер.

PIR/ADC/IMU releases прив'язані до абсолютної фази TIM3. Прострочені releases пропускаються без burst-catchup, `skipped` рахує кожен пропущений слот. `jitter` є фактичний інтервал між викликами мінус період. `deadline` включає пропущені слоти й виконання після наступної фазової межі. Pause-діагностика лишає scheduled callback, але пропускає звернення до сенсора. Не називати його успішним sample.

USART2 IRQ лише зберігає byte+час у кільце 128, рахує ORE/drop. EXTI0 фіксує перший PIR rising timestamp; співпалі події рахуються як coalesced. SysTick щомілісекунди викликає measure_service для unsigned-розширення TIM3 CNT. TIM3 IRQ не використовується. SysTick підтримує HAL tick. Critical sections захищають узгоджене читання CNT/UIF та event flag, а не всю прикладну логіку. SPSC RX має одного producer/consumer; volatile забезпечує видимість індексів у цій збірці Cortex-M0+, не робить довільну групу операцій атомарною.

TIM3: PSC=47, ARR=65535, APB timer=48 МГц. Роздільність 1 мкс; overflow кожні 65.536 мс, uint32 result wrap 4294.967296 с. Якщо interrupt заблоковано більше одного overflow, час може бути втрачено. DWT CYCCNT у цьому Cortex-M0+ не використовується. Підтримку таймера симулятором слід перевірити до прийняття чисел.

`task_permille` є часткою часу instrumented work без подвійного підрахунку вкладеного export/save. Це не вся зайнятість CPU: IRQ, перевірки готовності та busy spin не включено. main не викликає WFI, тому `awake_pct=100` є властивістю реалізації, не виміром енергоспоживання. Loop включає і накладні витрати профілювання.

## Зміна часової бази після пілота

Версія tree1566c431… має підтверджені unsigned timing spikes і непридатна для фінальної таблиці часу. Нова tree8976c45… розширює CNT через `desk_clock_observe`, без TIM3 overflow IRQ. `measure_service` із SysTick і звичайні читання забезпечують інтервал спостереження <65.536мс у штатному режимі. Обов'язкова умова: не можна пропустити цілий оберт CNT. Single-bank flash stall або маскування IRQ >65.536мс можуть втратити час; це залишається межею методу. Нова реалізація ще не підтверджена повторним simulator pilot, не вважати host test виміром C031.

Для фізичного C031 DS13867 Rev4, table43 задає page erase max40мс і64-bit program max125мкс. Окремий erase вкладається в один оберт TIM3 65.536мс за цих умов; це розрахункова передумова service-методу, а не підтверджена тривалість Wokwi. Незалежний зовнішній VCD/аналізатор потрібний для перевірки. Джерело: https://www.st.com/resource/en/datasheet/stm32c031c6.pdf
