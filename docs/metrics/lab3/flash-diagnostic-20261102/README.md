# Діагностика стирання flash

Окрема збірка з тим самим HAL і журналом, доповнена протоколом результатів `flash_erase`; ELF SHA-256 `5b7ae77f5bf6295e5173ee6e3328a1b42a1ce79fde98a9c9bbe9c7c9933ee8a6`. Вона не є вихідним ELF S1–S3. Після `journal`, `storage probe`, `save`, `journal`: початково 128 пошкоджених записів; HAL unlock і erase повернули OK, pageerr=FFFFFFFF, HAL error=SR=0 для сторінок 14/15; readback 0/2048 байтів FF на кожній, перші 4 байти 00. Тому перевірка стирання відхилила SAVE, програмування і CRC у цьому досліді не виконувались. HAL визначає сторінку як 2048 байтів, базову адресу flash 0x08000000; сторінки 14/15 відповідають 0x08007000–0x08007fff, область зарезервована linker script. Спостереження локалізує розходження в поточному виконанні Wokwi; точний внутрішній механізм або стан фізичного MCU не встановлено. Успішний reset/power-cut не доведено. Host-тести CRC/обривів перевіряють алгоритм на модельному сховищі, а не цю периферію.
