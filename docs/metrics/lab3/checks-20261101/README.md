# Додаткові сценарії DeskLight

Сценарії виконані в Wokwi з ELF SHA-256 `d4c6ed31844d8988d0530fddeb7923e3aed11502e20d534d9e1c462bf6516843`. Це модельні, а не фізичні вимірювання. Скомпілювати власний chip можна офіційним образом `wokwi/builder-clang-wasm` з `--target=wasm32 -nostdlib -Wl,--no-entry -Wl,--export=chip_init -Wl,--import-memory -Wl,--export-table`. Для повторення потрібні відповідні прошивка ELF/HEX, не включені до цього каталогу; перед запуском перевірити хеш.

## Затримана доступність

`startup` використовує мінімальний тестовий I²C-інтерфейс замість MPU6050: NACK до 3 с, після — ID 0x68 і статичний вектор 1 g. Це не точна модель сенсора. D6 фіксує ready, D2 — TX; декодер `decode_vcd.py` відновлює 115200 8N1. D6 READY з 3,000 с; STATUS t=1, SELFTEST ERROR, STATUS t=3207 valid=1/fault=0. Початок рядка за VCD 3,214868 с: 214,868 мс після READY. Окремий пізній serial `uart.raw` служить незалежною перевіркою декодованих рядків після підключення, не охоплює старт.

## SDA та UART

`sda-uart`: тестовий компонент утримує SDA LOW 15–20 с за D3 VCD; STATUS t=15010 invalid/fault, t=20708 valid/no fault. Шість вікон по близько 10 с MCU, цільові темпи з хоста 1/2/5/10/20/50 команд/с; фактичні середні між першою й останньою відправками 1,00/1,98/4,83/9,63/17,95/45,99 команд/с; кількості 10/20/49/97/180/472. Перші п'ять snapshot мають нуль лічильників втрат. У шостому `tx_drop=450` означає 450 відхилених повідомлень, `rx_drop=ore=0`. Кількість REPLY дорівнює кількості відправлених команд, але без ID їх неможливо повністю зіставити. RX у VCD не записано; частину COMMAND-маркерів втрачено. Точна межа між рівнями не встановлена.
